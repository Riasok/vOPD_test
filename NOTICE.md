# Source provenance

This repository collects experimental vOPD integrations prepared with Codex for Riasok. TRL and verl source snapshots retain their upstream license files and copyright notices. New integration changes follow the corresponding project's Apache 2.0 conventions.

The original `holi-lab/vOPD` reference snapshot had no top-level license file at its recorded revision; this workspace grants no additional license over that reference. The paper is linked to its authoritative source. Exact upstream revisions and local reviewed commits are recorded in `reports`.

Nested source folders are snapshots. They exclude git metadata, environments, caches, downloaded model weights, and credentials. Uninitialized upstream submodule commit references, if any, are recorded in `reports/public-snapshot.json`.
